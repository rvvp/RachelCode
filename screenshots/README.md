# 截图与静态展示页说明

当前目录里，建议优先查看以下新版静态展示页：

- `login-siana.html`
  登录页展示
- `admin-siana.html`
  管理员首页/资料列表展示
- `review-siana.html`
  管理员流转看板展示
- `edit-siana.html`
  A / B 填写页展示
- `detail-siana.html`
  资料详情页展示
- `c-siana.html`
  C 部门只读页展示

如果要直接拿 PNG 给汇报材料或交付文档使用，建议优先使用下面这组统一命名：

- `delivery-01-login.png`
- `delivery-02-admin-list.png`
- `delivery-03-workflow-board.png`
- `delivery-04-edit-form.png`
- `delivery-05-detail-view.png`
- `delivery-06-c-readonly.png`

说明：

- 以上 `*-siana.html` 是当前交付版的主展示页
- 旧版 `admin-home.html`、`c-home.html`、`login-brand.html` 等页面已经保留为跳转入口，打开后会自动跳到对应的新版页面
- 同名 `.png` 文件可用于汇报材料、文档或交付截图引用
